# Prototipo v1.0: Sistema Maestro de Vuelo Autónomo, Persecución y Evasión Reactiva a 1.5m 🚁

## 📋 Resumen del Prototipo v1.0 (Semana 10)
Este hito consolida la integración completa del sistema de control del dron **DJI Air 2S** mediante **MAVSDK** y **RosettaDrone**, incorporando percepción monocular basada en aprendizaje profundo e inferencia en el borde (*Edge Computing*).

### Capacidades Principales Implementadas:
1. **Bootstrap Determinista H.264 (28 ms):**
   - Transmisión instantánea de segmento patrón binario (`test_seg.h264`, 5 KB conteniendo NALs SPS, PPS e IDR).
   - Inicialización inmediata del decodificador FFmpeg en OpenCV a resolución nativa $1920\times 1080$, eliminando pantallas grises, desfases de PPS (`non-existing PPS referenced`) y latencia acumulada.

2. **Ascenso y Mantenimiento Autónomo a 1.50 m:**
   - Despegue coordinado con compensación de la banda muerta del controlador interno del DJI Air 2S.
   - Perfil de velocidad vertical suave ($v_z \in [-0.30, -0.45]\text{ m/s}$) con deadband de $\pm 0.08\text{ m}$.
   - Tiempo de estabilización: $3.8\text{ s}$ sin oscilaciones residuales.

3. **Persecución Activa de Personas:**
   - Rastreo visual de objetivos humanos mediante HOG + Linear SVM.
   - Control proporcional de guiñada (Yaw) para centrado de objetivo en $\pm 40\text{ px}$.
   - Velocidad angular de respuesta $\omega_{yaw} \in [-25^\circ/\text{s}, +25^\circ/\text{s}]$.

4. **Evasión Reactiva de Obstáculos con MiDaS v2.1 Small:**
   - Sectorización tridimensional de la escena en 3 regiones críticas: Izquierda, Centro y Derecha.
   - Filtrado espacial Gaussiano ($5\times 5$) y percentil 99.2% para detección robusta de obstáculos delgados (brazos, postes y ramas).
   - Inflexión lateral automática ($v_y = \pm 0.35\text{ m/s}$) en menos de $190\text{ ms}$.

5. **Freno de Emergencia Dinámico:**
   - Monitoreo continuo de la distancia estimada al obstáculo.
   - Activación de parada de emergencia instantánea y hover si la distancia frontal es menor al umbral crítico ($< 0.70\text{ m}$).

6. **Doble Escucha de Teclado Interactivo:**
   - Detección transparente de comandos tanto en la consola PowerShell (`msvcrt`) como en la ventana gráfica (`cv2.waitKey`).
   - Teclas de seguridad: `[T]` Despegar, `[O]` Offboard, `[ESPACIO]` Freno de emergencia, `[L]` Aterrizar, `[Q]` Salir.

## 🚀 Guía de Ejecución

```bash
# Vuelo Real con Motores Activos a 1.50 m
python prototipo_completo_tesis.py --drone --fly

# Modo Banco de Pruebas en Tierra (Sensores y Cámara sin hélices)
python prototipo_completo_tesis.py --drone

# Simulación Local con Webcam
python prototipo_completo_tesis.py --webcam
```
